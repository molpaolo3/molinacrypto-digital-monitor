# Changelog

## v0.8 - UI, Privacy Notice e Security LAB

Aggiornamento principale della dashboard desktop MolinaCrypto Digital Monitor.

### Novità principali

* Nuova interfaccia grafica più moderna e leggibile.
* Avvio della finestra in modalità massimizzata.
* Nuova navigazione laterale.
* Dashboard iniziale riorganizzata con card operative.
* Sezione "Risorse" sostituita con "Security LAB".
* Collegamenti diretti a Risk Score Checker online, Security LAB, Metodo Risk Score, MolinaCrypto Web3 Shield, glossario Crypto/Web3/Cybersecurity e checklist sicurezza crypto.
* Migliorata la fruibilità generale dell'app su desktop.
* Migliorata la disposizione dei pulsanti principali, evitando tagli o sovrapposizioni.

### Privacy e dati live

* Aggiunta informativa iniziale prima del caricamento dei dati live.
* Nessuna chiamata live viene eseguita prima della scelta dell'utente.
* Possibilità di accettare o rifiutare il caricamento automatico dei dati live.
* Corretto il flusso: se l'utente rifiuta all'avvio e accetta successivamente da "Aggiorna tutto", i dati live vengono caricati correttamente.
* Specificati i servizi esterni interrogati direttamente dall'app: molinacrypto.eu, Kraken API, mempool.space API, Alternative.me Fear & Greed Index e GitHub Advisories API.
* Chiarito che Google Analytics, Iubenda, Altervista Ads e altri script del sito non vengono caricati direttamente dall'app desktop, ma solo dalle pagine web aperte manualmente nel browser.

### Correzioni tecniche

* Correzione del comportamento del consenso live.
* Pulizia di vari warning segnalati dall'editor.
* Migliorata la gestione dei dati potenzialmente mancanti.
* File principale consolidato come MolinaCryptoDigitalMonitor.py.
* Preparazione della release Linux con avvia.sh e README dedicato.
* Struttura documentale pensata anche per successiva release Windows portable.
