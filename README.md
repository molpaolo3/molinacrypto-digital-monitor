# MolinaCrypto Digital Monitor

**MolinaCrypto Digital Monitor** è una dashboard desktop open source collegata a [molinacrypto.eu](https://www.molinacrypto.eu), pensata per aggregare in un’unica interfaccia dati e contenuti su:

- Bitcoin e criptovalute
- Web3 e digital innovation
- cybersecurity e vulnerabilità
- news esterne selezionate
- mempool Bitcoin
- Fear & Greed Index
- telemetria cyber aggregata

Il programma è sviluppato in Python con interfaccia Tkinter.

## Funzionalità principali

- Ultimi articoli pubblicati su molinacrypto.eu
- Feed news principali, extra e world news
- Prezzi crypto live tramite Kraken public API
- Pannello asset con grafico OHLC semplificato
- GitHub Security Advisories
- Bitcoin mempool e fee tramite mempool.space
- Fear & Greed Index tramite alternative.me
- Telemetria cyber aggregata tramite dati pubblici/cache del sito
