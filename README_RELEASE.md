# MolinaCrypto Digital Monitor v1.0

**Closed-source desktop release** for Linux and Windows.

Digital Monitor is the desktop intelligence client of the MolinaCrypto / Molina Security Lab ecosystem. The v1.0 interface unifies the main Cyberdeck information flows in a lightweight native desktop application.

## Modules

- Command Deck
- Threat Telemetry
- Cyber Attack Map with animated source → target arcs
- Attack Wire
- Exploit & Zero-Day
- IOC Vault
- Cyber Intel
- OSINT Scope
- Intel Deck
- Web3 Mesh
- AI Watch
- Crypto Market
- Bitcoin Network
- Diagnostics

## Data model

Cyber intelligence is primarily read through first-party endpoints under `molinacrypto.eu`. The desktop client displays normalized public information and does not represent individual telemetry events as forensic proof of a real-world attack.

The Crypto Market uses Kraken public market data. Bitcoin Network data is read through the MolinaCrypto first-party proxy used by the Cyberdeck.

## Source distribution

The v1.x source code is **not included** in official release packages. Official downloads contain only the compiled application and release documentation.

The historical v0.x project was previously published under its then-applicable open-source license. That historical license remains applicable to copies released under it; it does not apply to the separately released v1.x codebase.

## Security note

Verify the SHA-256 checksum before running a downloaded package. Download only from official MolinaCrypto channels.
